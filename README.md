# 🎵 C# Desktop Music Player

A lightweight desktop music player built with Windows Forms, NAudio, and TagLib#.

![Screenshot](screenshot.png)

## 🚀 Features
* **Formats:** MP3, WAV, FLAC, AAC, M4A, OGG, WMA, AIFF, ALAC.
* **Metadata & Art:** Extracts tags (Title, Artist, Album) and displays embedded cover art.
* **Controls:** Play, Pause, Stop, seekable progress bar, volume control with mute, and live timer.
* **Modes:** Repeat looping and Shuffle randomization.

---

## 📋 Requirements & Installation
* **Dependencies:** [.NET 10 Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)
* **Quick Install:** Download the latest [compiled x64 release zip](https://github.com/qasem-talaee/music-player/releases/latest), extract it, and run `MusicPlayer.exe`.
